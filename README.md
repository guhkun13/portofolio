# Teguh Atma Wijaya — CV website

Static CV site built from the [minimalist cv template](https://github.com/BartoszJarocki/cv) by Bartosz Jarocki (MIT, see LICENSE).

Content lives in `src/data/resume-data.ts`. The PDF version is `public/resume.pdf`.

```bash
pnpm install
pnpm build   # static output in ./out
```
